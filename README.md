# Telegram-бот HiggyGRAM (для bothost.ru)

Что делает бот:
- **Выдаёт номер** для входа на сайт: `+1`, `+7` или `+7 7` (Казахстан). Один Telegram — один номер.
- Код входа / смены номера / удаления аккаунта приходит **в этот же бот** (его отправляет сайт).
- **Пополнение H-STARS звёздами Telegram**: 1 ⭐ = 1000 H-STARS (число задаётся `HSTARS_PER_STAR` в `config.php` сайта).
- **Админ-панель** (`/admin`, только для `ADMIN_IDS`): выдать премиум-номер с любым кодом страны (вручную или случайный по коду страны),
  найти номер/пользователя, снять премиум-номер, статистика.

## Установка
1. В @BotFather создайте бота (или возьмите существующий), скопируйте токен. Включать платежи не нужно — звёзды (XTR) работают без провайдера.
2. Загрузите на bothost.ru **содержимое папки `telegram_bot/`** (main.py, requirements.txt). Файл запуска — `main.py`.
3. Задайте переменные окружения в панели bothost (или создайте файл `.env` по образцу `.env.example`):
   - `BOT_TOKEN` — токен бота
   - `SITE_URL` — `https://hostgta.ru`
   - `BOT_API_KEY` — длинный случайный секрет, **тот же**, что `BOT_API_KEY` в `config.php` сайта
   - `ADMIN_IDS` — ваш Telegram ID (узнать: @userinfobot), несколько — через запятую
4. Запустите. В логе должно появиться «Бот @… запущен».

## Как это связано с сайтом
Бот не подключается к базе — он ходит на `SITE_URL/bot_api.php` с секретом `BOT_API_KEY`. База, номера и баланс живут только на сайте.
Если сайт недоступен в момент оплаты, бот сохранит платёж в `pending_topups.json`, повторит зачисление и сообщит админам. Дублей не будет (платёж уникален по ID).

## Админ-панель: как выдать премиум-номер
`/admin` → «Выдать премиум-номер» → получатель: Telegram ID, `@username` в Telegram или username на сайте → «вручную» (например `+44 7700 900123`)
или «случайный по коду страны» (`1`, `7`, `77`, `44`, `380`…) → подтвердить. Старый номер получателя заменяется (один аккаунт — один номер).
Для **старых аккаунтов, созданных по почте**: выдайте номер по username на сайте — бот попросит Telegram ID владельца и привяжет его.
